## Overview

Personal portfolio website dengan tema **cyberpunk / terminal**.  
Dibangun pure HTML, CSS, dan JavaScript (no framework).

### Fitur

- Matrix rain background (live)
- Floating particles + connection lines
- Custom neon cursor + trail
- Glitch text effects
- Typing terminal animation
- Skill bars & live status fluctuation
- Scanline + grid overlay
- Responsive design

## How to Run

Cukup buka `index.html` di browser, atau pakai live server:

```bash
# Jika punya Python
python -m http.server 8080

# Atau Node
npx serve .
```

Lalu buka `http://localhost:8080`

---

## Deploy ke GitHub Pages

1. Buat repository baru di GitHub
2. Push semua file ke branch `main`
3. Settings → Pages → Source: Deploy from branch `main` / root
4. Website akan live di: `https://username.github.io/repo-name`
